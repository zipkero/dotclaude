# Rust 작업 기준

## 주석
- 모듈·크레이트 문서는 파일 맨 위 `//!`, 항목 문서는 `///`, 그 밖의 주석은 `//`로 쓴다.
- 문서화 주석의 첫 줄은 rustdoc 목록에 혼자 보이므로 한 문장 요약으로 쓴다.
- 공개 함수가 `Result`를 돌려주면 `# Errors`, panic할 수 있으면 `# Panics`, `unsafe fn`이면 `# Safety` 절에 그 조건을 적는다.
- 다른 코드 항목은 `` [`Name`] `` intra-doc link로 가리킨다.
