# 언어 공통 작업 기준

## 공통 기준
- 오류, null, 비동기, 취소, 리소스 해제처럼 놓치면 버그가 되는 부분을 먼저 보되, 검사는 외부 입력과 실패할 수 있는 호출에만 둔다.

## 주석
- 주석은 한국어로 쓰되, 기존 파일·디렉토리의 언어 관례를 따른다.
- 공개 함수·타입·상수에는 이름만으로 뜻이 통해도 문서화 주석을 단다.
- 외부 시스템 동작이나 호출 순서에 기대는 처리, 우회 코드, 다른 방법 대신 택한 구현에는 그 이유를 주석으로 적는다.
- 그 밖에는 diff와 대화를 모르고 이 파일을 처음 여는 사람이 놓칠 역할·동작·사용 조건을 적고, 코드를 말로 옮기기만 하는 주석은 쓰지 않는다.
- 변경 전후 비교, 수정 작업의 과정, 사용자 요청, 대화 내용, 작업 단계는 주석에 쓰지 않는다.
- 코드를 고치면 근처 주석이 아직 맞는지 보고, 틀리면 고치거나 지운다.
