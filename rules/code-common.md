## 주석
- 주석은 기존 파일·디렉토리의 주석 언어를 따르고, 관례가 없으면 한국어로 쓴다.
- 이유 주석에 더해, 이 파일을 처음 여는 사람이 놓칠 역할·동작·사용 조건도 지금 코드대로 적는다.
- spec·design·implement의 순서·이유·기대값이 필요하면 절·Task 번호 대신 내용을 직접 적는다.
